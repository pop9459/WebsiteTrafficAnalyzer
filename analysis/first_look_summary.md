Generated by `analysis/first_look.R` on 2026-10-21. Aggregates only.

> Update 2026-10-07: the exposed `.git` directory described below has been fixed. Apache now serves only `public/`, so these probes return 403. The data now runs past the fix (it covers the whole range in the Dataset section), so the exposure numbers below mix the period before and after it; `analysis/fix_effect_summary.md` compares the two.

## Dataset

- 395,121 requests over 104 days (3,802 per day), plus 68,333 error-log lines.
- 61.1% of requests arrive through Cloudflare (9406 edge addresses); 38.9% hit the origin server directly (4,662 distinct clients).
- 80.1% of all requests end in 4xx; 19.9% in 2xx.
- 3,481 requests (0.9%) are not valid HTTP (e.g. TLS handshakes on port 80).
- Outgoing response bytes: 9.55 GB in total, of which 9.07 GB (95%) answered probes for exposed files (mostly `/.git/objects/`).
