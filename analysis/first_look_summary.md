Generated by `analysis/first_look.R` on 2026-10-21. Aggregates only.

> Update 2026-10-07: the exposed `.git` directory described below has been fixed. Apache now serves only `public/`, so these probes return 403. The figures below describe the period before the fix.

## Dataset

- 298,296 requests over 86 days (3,474 per day), plus 44,530 error-log lines.
- 55.8% of requests arrive through Cloudflare (8364 edge addresses); 44.2% hit the origin server directly (4,058 distinct clients).
- 81.2% of all requests end in 4xx; 18.7% in 2xx.
- 3,143 requests (1.1%) are not valid HTTP (e.g. TLS handshakes on port 80).
- Outgoing response bytes: 9.51 GB in total, of which 9.07 GB (95%) answered probes for exposed files (mostly `/.git/objects/`).
